Port protocols

Ten protocols, five colors, four shapes. Inside a family the protocol code (OffBit) is the second signal: footer output, edge chip on hover, and the port's tooltip and aria-label. Auth is retired; its yellow now means navigation.

protocolcodefamily · colorshapesignal beyond color
localLOCALlocal · port-local = text-2circleOnly cream port; color alone is enough, code shown anyway.
electron-ipcIPCrequest · port-request = accentcircleShares marigold with HTTP/RPC/CLI: needs the IPC code.
httpHTTPrequest · port-request = accentcircleFamily default. Code shown on chip and footer.
rpcRPCrequest · port-request = accentcircleNeeds the RPC code.
cliCLIrequest · port-request = accentcircleNeeds the CLI code.
eventEVTevent · port-event = okdiamondDiamond. Family default.
scheduleSCHEDevent · port-event = okdiamondDiamond + SCHED code (clock-like work).
dataDATAdata · port-data = infosquareSquare. Family default.
stateSTATEdata · port-data = infosquareSquare + STATE code.
navigationNAVnavigation · port-nav = warntriangleTriangle; only yellow port.
